## The line

> One star. Waited an hour for a table, got Monday's cold coffee and a 6 a.m. meeting for dessert. The bill was my whole inbox.

25 words, 125 characters — one line of plain text, with no trailing newline.

## How to run

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when the variable is not set) and asserts the
written file matches the line exactly.
